## 1. Objetivo del proyecto
El objetivo de este proyecto fue recrear un diseño web con los conceptos que hemos visto (HTML Y CSS)

## 2. Tecnologías utilizadas
Para el desarrollo del proyecto utilizamos las siguientes tecnologías:
. HTML
. CSS
. Google fonts

## 3. Cómo organizamos el HTML
.header
   -Logo
   -Botón de configuración
.Main
    -Titulo principal
    -Textarea
    -checkboxes
    -card
    -density letter

Tambien use:
.section
.article
.div
.label
.span

## 4. Cómo resolvimos el CSS

.:root para las variables de colores
.flexbox para alineaciones
.max-whidt para controlar el hancho principal
.responsive design

## 5. Dificultades encontradas
Las principales dificultades fueron:
.Lograr que toda la página entre en pantalla sin scroll
.Ajustar correctamente los tamaños del contenido
.Controlar espacios y alineaciones entre componentes
.uso correcto de flexbox
